# LJT-Homepage

Personal academic homepage of **Junteng Liu**, first-year PhD candidate at the HKUST NLP Group, Hong Kong University of Science and Technology.

Built with Jekyll using the [Academic Pages](https://github.com/academicpages/academicpages.github.io) template, which this repository is a fork of.

## Site content

- `_pages/about.md` — the homepage: research interests and skills, education, research experience, publications, honors and awards, and contact information.
- `_pages/publications.html` / `_publications/` — the publications page, generated from one Markdown file per paper.
- `_config.yml` — site-wide settings and the author sidebar profile.
- `_data/navigation.yml` — header navigation.
